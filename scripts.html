Disable ArcGIS Pro Updates (Registry)

สคริปต์สำหรับปิดการตรวจสอบอัปเดตอัตโนมัติของ ArcGIS Pro.

วิธีใช้งาน:
  1. ดับเบิลคลิกไฟล์ .reg แล้วกด Yes เพื่อเพิ่มค่ารีจิสทรี จากนั้นเปิด ArcGIS Pro ใหม่เพื่อปิดการตรวจอัปเดต.
File: script/DisableArcGISProUpdates.reg

ArcGIS Offline Patch Auto Installer (Batch)

สคริปต์ช่วยติดตั้งแพตช์แบบออฟไลน์โดยอัตโนมัติ.

วิธีใช้งาน:
  1. นำไฟล์ .bat วางที่โฟลเดอร์ที่มีไฟล์ patch .msp อยู่
  2. เปิด CMD (Run as administrator)
  3. cd ไปที่ path ที่วาง .bat ไว้
  4. รัน install patch.bat
จะมี log แสดงแต่ละ patch ถ้าติดตั้งเรียบร้อย
File: script/Autoinstallpatch.bat
Open Download ZIP Recommended

ArcGIS Offline Patch Auto Installer (Linux)

สคริปต์ช่วยติดตั้งแพตช์แบบออฟไลน์โดยอัตโนมัติสำหรับ Linux (bash).

วิธีใช้งาน:
  1. นำไฟล์ .sh วางที่โฟลเดอร์ที่มีไฟล์ patch .tar อยู่
  2. ให้สิทธิ์รันสคริปต์: chmod +x autopatch.sh
  3. รันสคริปต์: ./autopatch.sh
สคริปต์จะแตกไฟล์ .tar ทั้งหมดในโฟลเดอร์ปัจจุบัน แล้วรัน applypatch ในแต่ละโฟลเดอร์ให้อัตโนมัติ พร้อม log แสดงผลแต่ละ patch
File: script/autopatch_linux.sh

PM Tools (SMB / NAS Monitoring)

เครื่องมือตรวจสอบ Performance, SMB Client event log และทดสอบการเชื่อมต่อ NAS สำหรับเครื่อง ArcGIS.

วิธีใช้งาน:
  1. ดาวน์โหลดไฟล์ .cmd แล้วดับเบิลคลิกเพื่อรันได้ทันที (ไม่ต้องมีความรู้ PowerShell) หรือดาวน์โหลด .zip ที่มีทั้ง .cmd และ .ps1
Latest release: v1.7.9
